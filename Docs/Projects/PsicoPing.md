# 🧠 PsicoPing

Jogo sério transdisciplinar para estimulação cognitiva, controle inibitório e suporte ao tratamento psicoterapêutico de crianças e jovens com Transtorno do Déficit de Atenção com Hiperatividade (TDAH).

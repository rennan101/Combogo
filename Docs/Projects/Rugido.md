# 🦁 Aplicativo Rugido

Aplicativo móvel desenvolvido para o registro de denúncias, acolhimento e consolidação de dados estatísticos de violações de direitos da população LGBTQIA+, formalmente integrado ao Guia Oficial da Defensoria Pública do Estado de Pernambuco.
